Each row disables one fix in a scratch copy of the repo and runs the full
suite. **RED means the suite caught it.** A GREEN row is a question, not a
diagnosis — the fix may be untested, or the code may be unreachable, and both

thing reports a single result about several, which is how the DATE_RE half of
F5-5 went untested behind a RED for the money half.
